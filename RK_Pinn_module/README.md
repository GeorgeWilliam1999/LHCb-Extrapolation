The home of the `rkpinn` package, its plan, and the index of what the project has built.

| Name | What it does | State |

## The contract

Experiments are not kept here. They live in `../experiments/`, one folder each.

## How to add to it

1. Read `WORKFLOW.md` first.
2. Follow the README of the directory the change belongs to.
3. Add a row above for anything new at this level and change the date.
