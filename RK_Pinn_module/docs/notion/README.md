## The contract

Notion is the system of record. When the page and this copy differ, the page wins and this copy is corrected.

## How to add to it

1. Edit the copy here.
2. Rehearse the change on a scratch page if it holds a table, a toggle or an equation.
3. Publish the change to the Notion page.
4. Fetch the page back and check that no table, image or equation came back as escaped text, and that the rest of the page is unchanged.
5. Change the date above.
